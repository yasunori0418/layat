# ユースケース（`use_case`）

* [開発中の手元 dotfiles を out-of-store symlink で参照し、編集と同時に反映しながら育てる](./20260802-01b896b4-04b9-40d0-bf9e-966eaf64c3d4-out-of-store-live-editing.md) - 手元の dotfiles リポジトリを開発している最中は、編集のたびに flake を更新して再適用するのは回り道になる。この場合に限り、明示関数 `layat.lib.mkOutOfStoreSymlink "/abs/path"` で Nixストアを経由しない symlink を張り、ファイル編集と同時に反映させる。
* [配置に失敗・後悔したとき CLI 単体で前の世代へロールバックして元の状態へ戻す](./20260802-0b6f60cb-3e98-4ee7-8929-4d94a29f0af6-generation-rollback-standalone.md) - `src` を更新して適用したところ、新しいバージョンのプラグインに不具合があった・意図しない内容が配置された、といった場面で、ユーザーは前の世代へ戻して復旧する。
* [プロジェクト repo 内へ nix store の物を devShell 入室のたびに配置してチームで共有する](./20260802-19a90989-0ae3-438f-8a75-4e1e2637f81c-project-mode-in-repo-placement.md) - layat の**中心的な配置モード**。任意のプロジェクトに layat を組み込み、root をプロジェクトルートに解決して repo 内の任意パスへ nix store の物を配置する（→ ADR-400cadd4-0151-470b-92ae-9b11aa8e9bed / ADR-560852e1-3d07-46b9-ae1a-d15f82d28a5e）。新規プロジェクトは `layat init project`、既に `flake.nix` がある既存 repo へは手動で組み込む（→ ADR-9fde06e2-fe42-4274-8af3-da2298cdaeae）。
* [役割ごとに config を分けて更新を独立させ、1 つの更新を他の役割へ波及させない](./20260802-1c280dce-7c72-44c0-95ea-d06344f62a47-independent-update-cycles.md) - home-manager のように全体を一括管理するのではなく、用途ごとに独立した配置単位を定義する。各配置単位は `layat.<name>` で識別され（1 つ = 1 profile）、独立した profile・世代系列として管理される（→ ADR-fe035038-4415-4a1e-aa5c-509fdfce9955）。
* [リポジトリの内容を copy で初回だけ配置し、その後はユーザーが手で編集して育てる](./20260802-403fbe32-b146-401b-8b53-fe67c1e169c5-copy-place-once-user-managed.md) - 配置したあとユーザー自身が編集したいファイルを、`method = "copy"` で配置する。store へのsymlink は read-only で編集できないため、この用途には copy を使う。
* [既に home-manager / NixOS / nix-darwin を使っている環境へ layat をモジュールとして組み込む](./20260802-d39c1994-f9a5-4860-80ba-f6e584adaf14-module-integration.md) - 既に home-manager / NixOS / nix-darwin で環境を管理しているユーザーが、layat を CLI 単体としてではなくモジュールとして組み込み、host の activation（`home-manager switch` / `nixos-rebuild switch` 等）に layat の配置を載せる。flake-parts を使っているプロジェクト向けには `perSystem.layat` を `flake.layat.<system>` へ transpose する flakeModule も提供する（→ ADR-e6820da0-fce3-4aef-8b79-d53abbca6051）。
* [home mode で外部リポジトリの中身をバージョン固定して $HOME 配下の任意パスへ配置する](./20260802-f2436d68-91ff-4c48-b1df-47acefe4f464-home-mode-pinned-repo-placement.md) - ユーザーが `root = layat.lib.homeRoot` を明示した config を書き、外部リポジトリの内容（リポジトリ全体・サブディレクトリ・単一ファイル）をバージョン固定した状態で `$HOME` 配下の任意パスへ配置する。`layat apply <name>` で適用し、`src` の更新（flake input の更新 / npins update 等）後に再適用すると新しい内容へ切り替わる。
* [system mode で `/` 配下へ配置し、root 権限で世代とともに管理する](./20261018-6b8d31ea-3d5a-4334-aac7-8706df190e7d-system-mode-root-placement.md) - 管理者は、外部リポジトリの中身を `/etc` などシステム全体の場所へ配置したい。config の`root` に `layat.lib.systemRoot` を書き、root 権限で `apply` する。NixOS / nix-darwin のモジュールを使わず CLI 単体で使う環境でも、home mode と同じ CLI で配置と世代管理ができる。
