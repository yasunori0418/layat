# CASE-81d876af-a1e3-4348-a827-81c8ba7ef39b: apply_test.go — 終了コード集約・root フィルタ・退避行の出力

## 対象

`cmd/layat/apply_test.go`

## 検証内容

- **終了コードの優先順位** — 一般エラーと dryrun の conflict が同時に起きたとき一般エラーが
  勝つこと。単なる最大値でないことを、純粋な関数と集約経由の双方で固定する
- **部分失敗の継続と skip の区別** — 適用・skip・失敗の 3 値が別々に数えられ、失敗しても後続の
  config を止めないこと
- **root フィルタフラグの排他** — 未指定は無指定、単一指定はその値、複数指定はエラーになること
- **退避の出力表現** — 計画に退避の行が出ること、詳細レポートに退避の行が出ること、退避だけが
  起きた実行を no-op と誤って報告しないこと、完全に空の結果は no-op のままであること
- **ストリームの役割分離** — 計画は stdout、配置レポートは stderr へ出ること

適用の実装を関数注入で差し替え、nix を起動せずに集約と出力だけを検証する。
