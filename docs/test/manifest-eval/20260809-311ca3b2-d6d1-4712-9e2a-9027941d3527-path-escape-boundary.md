# TC-311ca3b2-d6d1-4712-9e2a-9027941d3527: パス脱出判定の境界をアサートする

## テスト条件

`escapesBase` / `isUnsafe` をテスト seam 越しに直接叩き、深さ 0 の境界を内側と外側の対で
アサートする。エラーの到達性は TC-e7ff0e6d-32d7-4ed6-8c2f-449dba34b2f6 の担当。

- `.` と空文字が深さを動かさないこと
- 単体の `..`・先頭の `..` が深さ 0 で即脱出になること
- 通常の下降が脱出にならないこと
- 深さがちょうど 0 まで戻る場合は脱出としないこと（境界の内側）
- その 1 つ外側で脱出とすること（境界の外側）
- 途中で `..` に当たっても深さが残っていれば脱出としないこと
- 途中で負になる場合は、後続が安全でも脱出が確定すること

境界は片側だけをアサートしない。内側と外側を対で置いて初めて、判定が境界ごと移動した場合を
検出できる。

`isUnsafe` については、深さ判定とは別に、絶対パスが `escapesBase` とは独立に拒否されること
（深さを一切見ずに弾くこと）を見る。
