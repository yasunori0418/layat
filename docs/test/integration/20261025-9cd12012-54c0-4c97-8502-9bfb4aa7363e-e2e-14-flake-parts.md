# CASE-9cd12012-54c0-4c97-8502-9bfb4aa7363e: e2e 14-flake-parts — mkApplyCommand を埋めた devShell が project config だけを配置する

## 対象

`tests/e2e/scenarios/14-flake-parts.sh`（ハーネスは `tests/e2e/run.sh` / `tests/e2e/lib.sh`）

## 検証内容

`flakeModules.default` を import した flake-parts の fixture に projectRoot と homeRoot の config を
1 つずつ持たせ、devShell の `shellHook` に `root = "project"` の `mkApplyCommand` へ `--no-wait` を
足した文字列を埋める。layat は局所パスの入力で参照し、flake-parts は layat の pin に追従させる。

- **入室だけで配置** — git repo のサブディレクトリから `nix develop -c true` を実行すると、
  project 側が git toplevel 配下に置かれ、内容が src と一致する
- **CLI だけの選別** — home 側は `--project-root` で外れ、隔離した `$HOME` に配置物が出ない
  （nix 自身が作る `.nix-*` / `.cache` は除く）
