# ADR-2230e78f-770a-447e-9c5d-6eba1e9a7359: モジュールは subdir の検査を lib に委ねる

- ステータス: 採用
- 日付: 2026-11-03
- 関連: GitHub Issue #585, `docs/spec.md`
- 起点: ADR-0064 §3 を書き直した

## 背景

`configs.<name>.subdir` には、絶対パス・`..` による root の外への脱出・空文字といった不正な値が
入りうる。lib の root marker の subdir 適用形は、これらをすでに評価時に検査している。

## 決定

モジュールは subdir の検査・正規化・空文字の読み替えを持たず、値をそのまま lib へ渡す。`""` を
null と同一視しない。不正な値は lib の評価エラーで止まる。規範は
REQ-068f2fb3-5459-4325-9359-c931b5049e0d に置く。

## 根拠

同じ規則を 2 か所で持つと、片方だけが変わって挙動が分岐する。lib の検査は standalone でも同じく評価時に
行われるので、モジュールで重ねて検査しても得るものが無い。`""` を null と読み替えると、lib が拒否する
値をモジュールだけが受け入れることになる。

## 棄却した代替案

### モジュールの側で subdir を検査し直す

lib と同じ規則を二重に持つことになり、片方だけが変わると挙動が分岐する。

### 空文字を null とみなす

standalone で拒否される値がモジュールでは通り、経路によって挙動が変わる。
