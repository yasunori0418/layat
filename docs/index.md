# layat のドキュメント

* [解決策（`solution`）](./solution/index.md) - layat が解く課題と、その解き方の全体像
* [ユースケース（`use_case`）](./use-cases/index.md) - 利用者が layat をどう使うかの場面
* [要件（`requirement`）](./requirements/index.md) - layat が満たす振る舞いの規範
* [設計（`design`）](./design/index.md) - 要件をどう実現するかの設計判断
* [品質（`quality`）](./quality/index.md) - 開発とリリースの品質を保つ規範
* [テスト計画（`test_plan`）](./test-plan/index.md) - 何をどの層のテストで確かめるかの方針
* [基盤（`infrastructure`）](./infrastructure/index.md) - CI・配布・ドキュメントサイトなどの基盤の構成
* [リスク（`risk`）](./risks/index.md) - 要件や設計が崩れたときに起きる脅威
* [ADR（`adr`）](./adr/index.md) - layat の設計判断の記録
* [SDR（`sara_adr`）](./sara-adr/index.md) - ドキュメントグラフの運用についての判断の記録
* [用語（`ubiquitous_term`）](./ubiquitous-language/index.md) - layat の用語の定義と避ける綴り
* [テスト条件とテストケース](./test/index.md) - 機能の区分ごとのテスト条件（`test_condition`）とテストケース（`test_case`）
