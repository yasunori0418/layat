* [--all は config ごとの SubjectResult を単一実行と同一形状で積む](./20260802-059eb4d5-63fb-4f8e-b705-11b5e2ed4ae5-json-all-subject-results.md) - **`--all` の複数 `SubjectResult`**（`apply --all` / `list-generations --all` / `gitignore --all`）: 選択した config ごとに `SubjectResult` を 1 つ `results\[\]` へ積む。**形状は単一 config 実行と完全に同一**で、`--all` を判別するフィールドは持たない（単一実行は N=1 の特殊形であって別文書ではない）。`specVersion` / `tool` / `command` / `dryRun` / `startedAt` / `finishedAt` はトップに 1 度だけ置き、`results\[i\]` を切り出しても単独で valid な文書にはならない。各 `results\[i\]` の中身（items / changes / generation / warnings / info）の写像規則は単一 config と同一で、`--all` 固有の写像は無い。例外は`list-generations --all` の subject 名で、2 つの profile 基底に同名 config がありうるため`<mode>:<name>`（user 基底は `home`、system 基底は `system`）と名付ける。
