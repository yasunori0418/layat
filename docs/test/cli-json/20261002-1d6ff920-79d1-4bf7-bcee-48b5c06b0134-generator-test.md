# CASE-1d6ff920-79d1-4bf7-bcee-48b5c06b0134: generator_test.go — 契約の失敗型・prebuilt 実装・テストダブル

## 対象

`internal/generator/generator_test.go`

## 検証内容

- **失敗型** — `generator.Error` の Error() が Message を返し、原因の error が Unwrap 越しに
  `errors.Is` / `errors.As` で届くこと。包み直しの後も `errors.As` で元の値が取れ、原因の無い
  ときは Unwrap が nil を返すこと
- **prebuilt の操作** — 相対パスで Discover したとき Build / DryBuild が絶対パスを返すこと。
  Roots が manifest.json の root と entries から導いた Targets を返し、AllRoots が prebuilt の
  失敗を返すこと。
  manifest.json の無い link-farm の Roots が prebuilt・Stage roots の失敗になり、原因の
  `fs.ErrNotExist` を保持すること
- **テストダブル** — 差し替えた戻り値と零値の既定、呼び出し記録の順序

prebuilt とテストダブルが契約のインターフェイスを満たすことはコンパイル時に検査する。nix の
プロセスは一切起動しない。
