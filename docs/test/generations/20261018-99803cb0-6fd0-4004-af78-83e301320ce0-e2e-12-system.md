# CASE-99803cb0-6fd0-4004-af78-83e301320ce0: e2e 12-system — user namespace の root で system mode の配置・世代・権限ゲートを往復する

## 対象

`tests/e2e/scenarios/12-system.sh`

`e2e_isolate` が `LAYAT_SYSTEM_PROFILE_BASE` / `LAYAT_SYSTEM_STATE_DIR` を隔離先へ向け、
`e2e_root_init` が root ランナー（`unshare -Ur`、不可なら `sudo -n`。どちらも不可なら失敗）を
解決する。fixture flake は `systemRoot` の config `sys` を宣言し、全コマンドを
`--root "$E2E_WORK/sysroot"` で実行する。

root = `/` の `<name>` 直キー経路（実 `/` へ配置し、`--all` に現れる経路）は e2e では触らない。
root = `/` の解決と直キーの記録位置は `internal/engine/` の Go テスト（`TestResolveRootSystem`・
`TestRecordForSystemDefaultBase`）、system 基底の `--all` 列挙は
`cmd/layat/list-generations_test.go`（`TestListGenerationsAllScansSystemBase`）が担当する。
本シナリオの `--all` 検査は、`--root` 経路の系列が `<roothash>/<name>` に置かれ、基底直下だけを
見る `--all` に現れないこと（除外）を固定する。

root ランナーが `sudo -n` の実 root 経路（`E2E_ROOT_MODE=real`）では、root の成果物が実 root の
所有になる。世代の本数の数え上げは root 側で行い、記録は非 root のまま直接読む。非 root の
変更系と読み取り系（`apply --dryrun` / `list-generations <name>`）の検査は、この経路と
user namespace 経路（`E2E_ROOT_MODE=userns`）の両方で行う。

## 検証内容

- **世代 1** — root の apply が `sysroot/.cfg/a` へ symlink を張り、内容が src と一致する
- **profile レイアウト** — profile 基底に `.root` が sysroot を指す `<roothash>` 系列があり、
  `sys/profile` と `sys/profile-1-link` が symlink として存在する
- **last-applied 記録** — `$LAYAT_SYSTEM_STATE_DIR/layat/<roothash>/sys/last-applied.json` が
  存在し、`linkFarm` が profile の指す link-farm と一致する
- **`list-generations`** — 単発は世代 1 件を返し、`--json` の subject 名は素の `sys` で
  `info.mode == "system"`。`--all --json` の subject 名の集合は空（`system:sys` が現れない）
- **世代 2** — entry を b へ入れ替えた root の apply で `.cfg/b` が配置され `.cfg/a` が消え、
  `profile-2-link` ができて世代が 2 件になる
- **非 root の変更系** — `apply` / `rollback` / `reset --yes` が exit 1 で、`--json` の subject
  `sys` の `errors[]` が `E_PERMISSION` を含む。前後で sysroot 配下・profile ディレクトリ
  （profile と世代リンク）・last-applied 記録が不変
- **非 root の読み取り系** — `apply --dryrun` と `list-generations` が exit 0 で、前後で不変。
  `list-generations` は世代 1・2 を返し、current は世代 2
- **rollback** — root の `rollback` で `.cfg/a` が戻り `.cfg/b` が消え、profile が
  `profile-1-link` を指す
- **reset** — root の `reset --yes` で配置が撤去され、profile のリンク先と世代の本数は動かない
