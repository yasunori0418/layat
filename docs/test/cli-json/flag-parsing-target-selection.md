# フラグの解釈と対象選択が仕様どおりで位置引数を飲み込まない

## 条件

CLI の表層が「どの対象に」「どの修飾で」作用するかを決める部分を確かめる。

- **値を省略できるフラグ** — 未指定・値なし指定・値あり指定の 3 状態が区別される。値なしで
  指定したときは既定値が入り、かつ**直後の位置引数を値として飲み込まない**（飲み込むと対象の
  名前が消え、意図しない対象へ作用する）。値を渡すには等号で明示的に区切る必要がある
- **対象の選択** — 名前を省略した既定・名前を明示した単一・全件の 3 つの使い方が区別される
- **フラグどうしの排他** — 対象の種別を絞るフラグは未指定なら無指定、単一指定はその値、
  複数指定はエラーになる。利用者に知らせずに片方を採用しない
- **修飾フラグと全件指定の合成** — 修飾フラグが全件指定と組み合わせたときも作用する

受理する値の集合も条件に含む。テンプレート名は定義済みの名前だけを受理し、空文字・大文字
小文字の違い・前後の空白を伴う名前・未知の名前を拒否する（受理集合が緩むと、意図しない参照先を
外部コマンドへ渡す）。

フラグの登録形も条件に含む。全コマンドに作用するフラグは最上位に persistent flag として登録され、
短縮形を持たない。

提供しないものの固定も条件に含む。バージョン表示はフラグとしてのみ存在し、同名のサブコマンドを
持たない。
