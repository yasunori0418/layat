# ADR-3dc21349-5504-48a4-ab88-812b92c3bdf9: -v で配置レポートを opt-in で出す

- ステータス: 採用
- 日付: 2026-11-03
- 関連: ADR-45380022-d959-4b22-aa05-5993ac1f3c87, ADR-9e328362-2e90-441a-8eca-40081ce71b1b, ADR-b3f3b68e-5096-46d1-bafd-53a9ab4711f4, ADR-c6bc7060-7af4-4889-9ce6-5800601c9dcc
- 起点: ADR-0031 §2・ADR-0033 §2d を書き直した

## 背景

成功時は、指定が無いときは何も出さない。それでも対話で使うときは、何が配置・除去・skip されたかを見たい場面が
ある。以前の `--verbose` は内部コマンドの開示を担っていて、配置の結果を詳しく見たいという用途と
噛み合っていなかった。機械向けの `--json` を足すにあたり、人向けのレポートとの関係も決める必要が
あった。

## 決定

`-v` / `--verbose` を付けたときだけ、配置レポート（サマリと target ごとの行）・skip の通知・
`--all` の完了サマリを stderr に出す。`-v` と `--json` は互いに独立したフラグで、どちらも他方を含まない。

レポートに含める内容とフラグの組み合わせは REQ-0a123b89-0399-4f76-b988-56a5f7e0becf に置く。

## 根拠

レポートを見たいときは `-v` を足すだけで済み、既定の出力は増えない。

`-v` は stderr に人向けのレポートを、`--json` は stdout に機械向けの結果を出す。宛先も読み手も
違う 2 つの opt-in で、連動させると片方だけ欲しい場面で制御できない。

## 棄却した代替案

### `--json` を付けたらレポートも出す

stdout の JSON だけ欲しいスクリプトにも stderr のレポートが付いてくる。

### レポートを常に出す

成功時の沈黙と両立しない。
