# TC-4d477235-5917-469b-926b-119266048643: 事前展開した apply コマンドが全 config を渡し、root の選別を CLI のフィルタだけに委ねる

## 条件

評価時の文字列と、それを実行した結果の配置の両方を確かめる。

- **文字列の形** — `root` の 4 値がそれぞれ正しいフラグになること、全 config が名前の辞書順で
  引用付きの `--manifest` に並ぶこと、実行ファイルが `layatPackage` から引かれること、
  省略・範囲外の `root` が評価時に止まること
- **CLI での選別** — project と home の link-farm を同じ `--manifest` の集合で渡し、フィルタなしで
  両方、`--project-root` / `--home-root` で各 root の config だけが置かれること。project 側は
  cwd ではなく git toplevel 配下に置かれ、nix は呼ばれないこと
- **実経路** — flake-parts の `config.layat` を渡した devShell に入るだけで project 側が配置され、
  home 側は `$HOME` に何も出ないこと
