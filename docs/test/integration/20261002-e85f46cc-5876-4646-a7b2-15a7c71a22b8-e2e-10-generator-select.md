# CASE-e85f46cc-5876-4646-a7b2-15a7c71a22b8: e2e 10-generator-select — --manifest 経路の環境非依存と入力不正の E_INPUT

## 対象

`tests/e2e/scenarios/10-generator-select.sh`

## 検証内容

- `LAYAT_GENERATOR=bogus` と未知キー入りの `layat.toml` を cwd に置いた状態で、ビルド済み
  link-farm を渡す `apply --manifest` が exit 0 で配置すること（activation の環境不定に耐える）
- `apply --generator bogus` が exit 1 + stderr 1 行で止まり、`--json` で `E_INPUT` を返し、
  何も配置しないこと
- 未知キー入りの `layat.toml` を置いた `apply` が同じく exit 1 + 1 行・`E_INPUT` で止まること
- `LAYAT_GENERATOR=nix` の `apply` が通常どおり配置すること

実 nix で fixture flake を評価・ビルドする。
