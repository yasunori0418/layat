# REQ-068f2fb3-5459-4325-9359-c931b5049e0d: HM モジュールは configs.<name>.subdir が非 null の config を homeRoot の subdir 適用形で組み、全 target を $HOME/<subdir>/ 配下に置く

## 仕様

- `configs.<name>.subdir` が非 null の config は `homeRoot { subdir = <subdir>; }` を root にして
  manifest を組む。root は home のままで、全 target が `$HOME/<subdir>/` 配下になる
- null の config は素の `homeRoot` で組む。subdir はその config の target にだけ効き、他の config の
  target は変わらない
- モジュールは subdir を検査・正規化しない。不正な subdir は manifest の評価で eval エラーになる
- `root` オプションは公開しない
