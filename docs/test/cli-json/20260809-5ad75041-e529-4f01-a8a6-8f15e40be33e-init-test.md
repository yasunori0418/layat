# CASE-5ad75041-e529-4f01-a8a6-8f15e40be33e: init_test.go — テンプレート名の受理集合と subject を持たない文書形

## 対象

`cmd/layat/init_test.go`

## 検証内容

- **展開コマンドの引数列** — テンプレートの参照先とテンプレート名を組んだ引数列になること。
  既定の参照先と、環境変数で局所の参照先へ差し替えた場合の双方で同じ形になること
- **テンプレート名の受理集合** — 定義済みの 2 つの名前だけを受理し、空文字・大文字小文字の
  違い・末尾に空白を伴う名前・未知の名前を拒否すること
- **subject を持たないコマンドの文書形** — 結果が空配列であり、実行の事実（テンプレート名と
  参照先）がエンベロープ直下の `info` に載ること
- **`info` の境界** — テンプレート名を拒否した実行は `info` を設定する前に失敗するため、
  `info` がキーごと不在であること（値の struct を出すと空文字を含む文書になる）
