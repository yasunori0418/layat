# CASE-2def907b-3815-4801-8ea6-03662ee66aa3: checks.darwin-module — nix-darwin の postActivation の配線を評価アサートで検証する flake check

## 対象

`flake.nix` の `checks.darwin-module`（fixture は `tests/modules/darwin-module.nix`、対象のモジュール
実体は `modules/nix-darwin.nix`）。darwin 以外の system では空の派生に差し替わる

## 検証内容

`darwinSystem` を評価し、`system.activationScripts.postActivation.text` に対してアサートする。
起動の形は評価時に検査し、崩れていれば darwin の check の drvPath の評価が失敗する。
このため darwin 以外のホストから drvPath を評価するだけでも退行が露見する。

- `postActivation` が engine を `apply --all` で 1 回だけ起動し、名前つき config ごとの
  ビルド済み配置物を名前の辞書順に並べ、既定の `--jobs 0` と既定サフィックスの退避フラグを
  付けていること
- `--dryrun` を付けないこと
- 利用者が `postActivation` に追記した内容が残ること
- config が 1 つも無いとき engine を起動しないこと
- darwin 上でビルドしたときは、各 config の文書が root の種別として system を固定していること

nix-darwin はこの check のためだけの入力として持ち込み、ライブラリ本体とモジュール本体には
依存を波及させない。
