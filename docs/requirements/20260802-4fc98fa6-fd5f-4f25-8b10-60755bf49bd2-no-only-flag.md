# REQ-4fc98fa6-fd5f-4f25-8b10-60755bf49bd2: 一部 entry だけを適用する --only は提供しない

## 仕様

`--only`（一部 entry だけ適用）は profile 世代の atomic 性と衝突するため提供しない。
選択的更新は config（`layat.<name>`）の分割で担保する。
