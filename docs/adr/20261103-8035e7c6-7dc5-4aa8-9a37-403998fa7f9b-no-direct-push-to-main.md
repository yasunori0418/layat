# ADR-8035e7c6-7dc5-4aa8-9a37-403998fa7f9b: main への直接 push を ruleset で禁じる

- ステータス: 採用
- 日付: 2026-11-03
- 関連: ADR-bff01b65-ddb8-46ce-8ffe-ed33ad354511
- 起点: ADR-0030 §1b を書き直した

## 背景

layat は main へ直接コミットせず、ブランチを切って PR 経由でマージする運用を取っている。
main へのマージにはテストの成功を必須にした（ADR-bff01b65-ddb8-46ce-8ffe-ed33ad354511）が、
PR を通らない直接の push には、この条件が掛からない。

## 決定

main の ruleset に `pull_request` のルールを置き、main への直接の push を禁じる。bypass は
許さない。

ruleset の構成は INF-8b97573f-d4d6-4abf-85e2-d859afbd96c6 に置く。

## 根拠

直接の push を塞がないと、required status check は PR を通った変更にしか効かない。main への
変更を全て PR に通すことで、テストの成功という条件が main の全ての変更に掛かる。運用ルールの
「main へ直接コミットしない」も、技術的に担保される。

## 棄却した代替案

### 直接の push を運用ルールで禁じるだけにする

強制力が無く、手元の操作の誤りで main へテストを通らない変更が入りうる。
