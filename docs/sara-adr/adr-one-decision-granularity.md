# ADR は単独で覆せる 1 つの決定だけを書く

- ステータス: stable
- 日付: 2026-11-01
- 関連: GitHub Issue #499, `docs/agents/adr-rules.md`
- 起点: Issue #499 の grilling（2026-11-01）で確定

## 背景

layat の ADR は、1 本に複数の決定を束ねて書いてきた。後から 1 つの決定だけを変えると、元の ADR に
改訂注記を足して「この節だけが変わった」と示すしかない。改訂を 4 回以上受けた ADR は 13 本あり、
どの決定がいまも有効かは注記を順に読んで組み立て直さないと分からなくなっていた。

## 決定

1 本の ADR には、単独で覆せる 1 つの決定だけを書く。判定の問いと、タイトル・`justifies` の本数を
分割の兆候として見る目安は `docs/agents/adr-rules.md` の「粒度: 1 本に 1 つの決定」節に置く。

## 根拠

1 本に 1 決定なら、決定を変えるときに ADR を丸ごと置き換えられる。部分改訂の注記が要らなくなり、
有効な ADR の本文がそのまま現時点の決定になる。

「単独で覆せるか」を基準にするのは、片方を覆すともう片方が意味を失う決定どうしまで分けると、
置き換えのたびに複数の ADR を同時に直す必要が出るため。

## 棄却した代替案

### テーマ単位で 1 本にまとめる

関連する決定を 1 本に集めると通読はしやすい。ただ、テーマ内の 1 決定を変えるたびに部分改訂が
要り、いまの問題がそのまま残る。

### `justifies` の本数で機械的に分割する

本数は決定の数を表さない。1 つの決定が多くの item を決めることもあるので、目安にとどめる。
