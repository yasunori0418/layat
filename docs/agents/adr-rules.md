# ADR の規則

ADR の規則は次の 2 本の quality item が持つ。

- 粒度・本文の構成・統合と分割の手順・`justifies` の選定基準: [ADR は 1 本に 1 つの決定を 4 節で書き、justifies は規範の形成に寄与した item へ張る](../quality/adr-one-decision-four-sections-justifies-by-contribution.md)
- 記録と接続の義務と、ステータス・出典・丸ごとの置き換え・採番の手引き: [設計判断は ADR に記録し、改訂の書き戻しと item への接続を同じ変更の中で完了させる](../quality/adr-decisions-recorded-and-connected.md)
