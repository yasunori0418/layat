# CASE-16289504-60e7-4046-9deb-7e2c962c5abf: apply_all_conflict_test.go — 前段衝突検査のバケット判定・選択集合・build 前停止・単一 apply 非検査

## 対象

`cmd/layat/apply_all_conflict_test.go`

## 検証内容

- **バケット規則** — 判定関数に rootKind 別・fixed の root 値別・fixed と project・`--root`
  指定時の組み合わせを与え、衝突の有無が規則どおりになること
- **選択集合** — 選択外の config 同士が衝突していても、選択された config だけを見て通ること
- **エラーメッセージ** — 衝突 target と両 config 名を含み、衝突していない target を含まないこと
- **`--json` の載り方** — 判定エラーをそのまま出力したエンベロープが適合検査を通り、
  トップレベル `errors[]` に `E_LAYAT_FAILED` が 1 件、`results[]` が空であること
- **build 前停止** — 呼び出しを記録する偽の nix を PATH 先頭に置いて `apply --all` を実際に
  駆動し、衝突時の nix 呼び出しが一括 eval の 1 回だけであること（`--dryrun` でも同じ）。
  停止時はトップレベル `errors[]` に 1 件載り `results[]` が空であること
- **選択集合と `--root` の配線** — 同じ偽 nix で、`--home-root` の選択外の衝突では build へ
  進み、`--root` 指定では rootKind の違う config 同士が衝突として止まること
- **単一 apply の非検査** — 同じ偽 nix で名指しの apply を駆動し、一括 eval が現れず、
  eval 1 回と build 1 回に進むこと
