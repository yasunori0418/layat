# 古くなった配置の除去は記録どおりの symlink だけに限る

- ステータス: stable
- 日付: 2026-11-01
- 起点: ADR-0002 §決定（削除の安全不変条件）を書き直した

## 背景

古くなった配置の除去は利用者のホームディレクトリやプロジェクトのファイルを消す操作になる。layat が
置いたつもりの target を、利用者が実ファイルや別のリンクへ差し替えていることもある。何を
消してよいかの安全側の条件が要る。

## 決定

古くなった配置の除去で消してよいのは、比較の基準の manifest が「layat が配置した」と記録し、かつ現状も
その記録どおりの先を指している symlink だけとする。通常ファイルや layat が管理していない
リンクには触れない。記録と実体が食い違えば消さずに警告する。比較の基準が空（初回）なら何も消さない。

不変条件の細目は [古くなった配置の除去は前世代の記録通りを指す symlink のみに限り、copy は消さず孤児を警告する](../requirements/stale-removal-invariants.md) に置く。

## 根拠

誤って消したファイルは取り戻せないが、消し残しは警告で気づける。利用者が差し替えた実ファイルを
壊さないことを、除去の網羅性より優先する。home-manager の cleanup も同じ保守的な条件で除去する。

## 棄却した代替案

### 新しい manifest に無い target を一律に除去する

利用者が差し替えた実ファイルを消してしまう。
