# CASE-cd3e3428-3fe0-4d33-a64c-1931ac11d07d: backup_flag_test.go — 値を省略できるフラグが位置引数を飲み込まない

## 対象

`cmd/layat/backup_flag_test.go`

## 検証内容

- **3 状態の区別** — フラグ未指定・値なし指定・値あり指定が区別されること。値なしで指定した
  ときは既定のサフィックスが入り、値ありのときは指定した値が入ること
- **等号区切りの必須性** — 値なしで指定したフラグが直後のトークンを値として飲み込まず、
  位置引数として残すこと。飲み込むと対象の名前が消え、意図しない対象へ作用する

コマンドを実行せず、フラグの解析だけを単体で駆動する。
