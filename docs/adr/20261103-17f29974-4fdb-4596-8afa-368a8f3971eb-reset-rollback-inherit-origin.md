# ADR-17f29974-4fdb-4596-8afa-368a8f3971eb: 記録を書き直す操作は記録済みの出所を引き継ぐ

- ステータス: 採用
- 日付: 2026-11-03
- 関連: GitHub Issue #580, #498
- 起点: Issue #498（epic: v1.0 前に残っている挙動の穴を埋める）の grilling（2026-10-31）。ADR-0070 §4 を書き直した

## 背景

reset と rollback も記録を書き直す。どちらの操作も新しい manifest を生成しないので、apply
と違って今回の出所を持たない。

## 決定

reset と rollback は、記録を書き直すときに記録済みの出所を引き継ぐ。記録に出所が無ければ、
出所を省いて版 2 で書く。

## 根拠

どちらの操作も出所を新しく決める材料を持たないので、記録済みの値を保てば情報を失わない。
出所を省いて書いた記録は、次の apply で出所を比べずに今回の出所が書き込まれる。

## 棄却した代替案

### 書き直すときに出所を消す

次の apply が出所を比べられず、別の出所からの上書きに気付けなくなる。

### rollback では戻り先の世代から出所を読む

世代は出所を持たない。出所を持つのは記録だけである。
