# project mode の root が git toplevel へ一意に解決し外では曖昧に成功しない

## 条件

配置先の起点が呼び出した場所に依存しないことを確かめる。

- **どこから呼んでも同じ** — リポジトリ内のどのサブディレクトリから呼んでも同一の toplevel へ
  絶対パスで解決されること
- **リポジトリ外での明示的な失敗** — 曖昧に成功せず失敗すること。この検証自体が隔離を要する
  点に注意が必要で、テスト用の一時ディレクトリの祖先がたまたまリポジトリだと誤って成功する。
  探索の上限を環境変数で切って隔離することがこの条件の一部である。失敗は対象のディレクトリを
  添え、リポジトリの外であることを判別できること
- **リポジトリの外とそれ以外の失敗の区別** — ディレクトリが存在しないなど、リポジトリの外では
  ない理由で git が失敗したときは、リポジトリの外と報告しないこと。対象のディレクトリと git の
  診断の 1 行目を添えて失敗すること
- **解決手段が無い場合の扱い** — git を辿れない環境で、判別可能な形で失敗すること

実際の配置まで通した処理でも同じ起点が使われることを確かめる。一時的なリポジトリを作り、その
toplevel の直下へ配置されること、および再実行が冪等であることを見る。
