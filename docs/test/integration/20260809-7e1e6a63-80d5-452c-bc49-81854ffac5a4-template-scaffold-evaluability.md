# TC-7e1e6a63-80d5-452c-bc49-81854ffac5a4: 展開したテンプレが局所参照へ差し替えた上でそのまま評価を通る

## 条件

はじめて使う人が最初に得る成果物が、手を入れずに評価を通ることを確かめる。

- **全テンプレートの展開** — 定義済みのテンプレートそれぞれについて、空のディレクトリへ
  展開でき、想定した構成物が現れること（テンプレートによって同梱物が異なる）
- **展開物の評価妥当性** — 展開直後の状態でそのまま評価が成功すること。独自の flake 出力に
  由来する警告は許容し、警告の有無ではなく評価の成否で判定すること
- **参照の循環の回避** — テンプレートが参照する layat を、手元のリポジトリへ局所的に差し替え
  られること。差し替えないと公開版を見に行き、手元の変更が検証に反映されない。差し替えの
  経路は展開時と評価時の双方に必要である
- **主体を持たないコマンドの出力** — 展開の実行が subject を持たない文書として、実行の事実を
  エンベロープ直下の情報として載せること

配置の動作そのものはこの条件に含めない（他の条件が受ける）。展開と評価の妥当性に限る。
