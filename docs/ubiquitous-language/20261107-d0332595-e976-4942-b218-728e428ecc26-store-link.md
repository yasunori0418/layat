# UBQ-d0332595-e976-4942-b218-728e428ecc26: store link

## Definition

The core, default placement: a symlink whose destination is a Nix store path. The default path that guarantees reproducibility. "Unification" means making the store the default/core and demoting out-of-store to an explicit exception.

## Avoid

Confusing it with out-of-store symlink; calling it a "copy".

## 定義

コア・デフォルトの配置。配置先が Nix store パスである symlink。再現性を担保するデフォルトの使い方。「unification（統一）」とは、ストアをデフォルト / コアにし、out-of-store を明示的な例外へ降格することを意味する。

## 避ける表現

out-of-store symlink と混同すること、「コピー」と呼ぶこと。
