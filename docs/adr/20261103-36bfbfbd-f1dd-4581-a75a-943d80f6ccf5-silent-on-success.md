# ADR-36bfbfbd-f1dd-4581-a75a-943d80f6ccf5: 指定が無いときは成功時に何も出力しない

- ステータス: 採用
- 日付: 2026-11-03
- 関連: ADR-45380022-d959-4b22-aa05-5993ac1f3c87, ADR-9e328362-2e90-441a-8eca-40081ce71b1b, ADR-b3f3b68e-5096-46d1-bafd-53a9ab4711f4
- 起点: ADR-0031 §1・§4 を書き直した

## 背景

以前の CLI は、`apply` / `reset` / `rollback` が成功すると配置レポート（サマリと target ごとの行）を
指定が無いときも stderr に出し、`--quiet` で抑えていた。成功はいちばん多い結果で、shellHook から呼ぶとシェルに入る
たびにレポートが流れる。静かにしたい呼び出し側（shellHook・スクリプト・CI）は一律に `--quiet` を
付けることになり、常に出したうえで呼び出し側ごとに抑えるという、本来とは逆の形になっていた。

## 決定

`apply` / `reset` / `rollback` が成功したとき、配置レポート・skip の通知・`--all` の完了サマリ・
「対象 config なし」の通知を、指定が無いときは出さない。warning と error は常に stderr に出す。
何も付けなければ沈黙するので、`--quiet` は持たない。

warning / error と `reset` の確認プロンプトを沈黙の対象外にすることは
REQ-8ef34101-8150-4124-92d5-94fabe6b5d90 に、`--quiet` を提供しないことは
REQ-0a123b89-0399-4f76-b988-56a5f7e0becf に置く。

## 根拠

成功は終了コード 0 で伝わる。成功時に何も出さなければ、目に入るのは失敗と警告だけになる。shellHook も
フラグを足さずに静かになる。

指定が無いときに何も出さないなら、`--quiet` には抑える出力が無い。残しても何もしないフラグになり、
指定が無いときも何かが出るという誤解を招く。

## 棄却した代替案

### 指定が無いときもレポートを出し、`--quiet` を残す

以前の形で、静かにしたい呼び出し側がフラグを付け続けることになる。

### `--quiet` を受理して無視する

既存の呼び出しはそのまま動くが、意味の無いフラグが残り、指定が無いときも出力があるかのように読める。廃止した
時点の利用者は限られており、互換を保つ利点は小さい。
