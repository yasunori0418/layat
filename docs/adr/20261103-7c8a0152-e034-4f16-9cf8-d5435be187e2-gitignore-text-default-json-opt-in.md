# ADR-7c8a0152-e034-4f16-9cf8-d5435be187e2: gitignore は行指向の出力を既定のまま JSON を opt-in にする

- ステータス: 採用
- 日付: 2026-11-03
- 関連: ADR-c6bc7060-7af4-4889-9ce6-5800601c9dcc
- 起点: ADR-0033 §1b を書き直した

## 背景

`gitignore` は、1 行に 1 パスの target を stdout に出す。利用者はこの出力をそのまま `.gitignore` に
足して使う。全サブコマンドが `--json` を受けるにあたり、すでに機械可読な行の契約を持つ `gitignore`
の既定の出力をどうするかを決める必要があった。

## 決定

`gitignore` の既定の出力は行指向のまま変えず、`--json` を付けたときだけ JSON に切り替える。行と
JSON の 2 つの契約が並ぶことを受け入れる。

`--json` のときに行指向の出力を出さないことは REQ-2353259f-5878-452a-8e11-3445de69abc2 に置く。

## 根拠

行指向の出力は、`.gitignore` へ追記する既存の使い方を支える契約で、変えると、行を読む既存の消費者が動かなくなる。
構造化して読みたい消費者は `--json` を付ければよい。行の契約は互換のため、JSON は構造化した消費の
ための opt-in として、役割が分かれる。

## 棄却した代替案

### `gitignore` の既定を JSON にする

全コマンドの出力が JSON に揃うが、`.gitignore` へそのまま足す使い方ができなくなる。

### `gitignore` だけ `--json` を受けない

契約は 1 つで済むが、全サブコマンドで `--json` を受けるという方針に例外を作る。
