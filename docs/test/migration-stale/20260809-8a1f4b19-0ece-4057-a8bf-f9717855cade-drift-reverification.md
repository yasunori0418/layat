# TC-8a1f4b19-0ece-4057-a8bf-f9717855cade: 除去直前の drift 再検証

plan 時に除去対象と判定された target が、実際の unlink までの間に不変条件から外れた場合
（リンク先が別の場所を指すようになった / symlink でなくなった / 消えた）を検出し、記録された
除去をそのまま実行しないことを検証する。drift の同値類ごとに確認する。

drift 検出時の分岐は処理によって異なるので、両方を条件に含む。古くなった配置の除去では対象を保持して
警告に留め、後続の除去アクションを止めない（1 件の drift が残りの除去を巻き添えにしない）。
配置前除去では、子が「祖先は消える」前提で無条件の新規配置として計画済みであるため、
skip せずエラーで停止する。

unlink 自体が失敗した場合（不変条件は保たれているが os.Remove が失敗）が、drift と区別されて
エラーになることも併せて検証する。
