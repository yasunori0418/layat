# 移行の全か無かと収束

ディレクトリ移行の途中に移行不能な実体（foreign な実ファイル・非空サブディレクトリ）が
見つかったとき、移行可能だった兄弟が一つも除去されないことを検証する。「1 つでも塞がれていれば
ツリー全体を移行しない」という規則が、plan 段階での停止として現れることを含む。

配置前除去まで進んだ後に中断した場合について、同じ apply を再実行すると元の目標状態へ
収束することを検証する。中間状態から手作業なしで復帰できることがこの条件の要点である。

複数世代にわたる往復（dir symlink → per-file → dir symlink）でも各世代で収束することを含む。
