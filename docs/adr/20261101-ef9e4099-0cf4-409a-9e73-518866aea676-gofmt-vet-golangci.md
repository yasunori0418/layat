## 背景

engine と CLI は Go で書く。Go のコードの整形と静的解析に何を使い、どこで実行するかを決める
必要がある。

## 決定

整形は treefmt に gofmt を加えて行う。静的解析は go vet と golangci-lint を `nix flake check` の
check derivation として実行する。

整形と静的解析をマージ前の自動検証に含める規範は QA-a92341b9-c873-406e-8b70-a64f56d8a7d6 に置く。

## 根拠

gofmt は Go の標準の整形器で、書式について議論する余地を残さない。treefmt には nix の整形が
すでに載っているので、Go を加えても整形を実行するコマンドは treefmt 1 つのままになる。go vet と golangci-lint を
check derivation にすると、CI と同じ判定を手元の `nix flake check` で得られる。engine 層の
依存を標準ライブラリに絞っている（ADR-fdb8003f-db36-424b-8484-6f2fd57a3027）ので、解析は軽い。

## 棄却した代替案

旧 ADR-0025 §6 は、整形器と解析器の選定について代替案を記録していない。
