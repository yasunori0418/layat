# TC-b329cafd-06c3-4b87-8357-229b69e5ba5c: plan 計算の純粋性と網羅

plan の計算が (前世代 manifest, 新 manifest, root, FS プローブ) のみを入力とし、fake FS を
差し込むだけで分類の全パターンを table-driven に列挙できることを検証する。実 FS へ触る実装が
含まれればこの条件は成立しなくなるため、fake FS だけでテストが完結すること自体が検証対象である。

分類の網羅（新規 / 張替え / foreign / conflict / 祖先移行 / 実 dir 移行）に加えて、
除去順序のような plan の構造的性質、および未知の method がエラーとして弾かれることを含む。
実 FS 側での再検証（除去直前の不変条件の再確認）は `migration-stale` 対象の担当。
