# CASE-96b537f7-0bc9-4669-bead-743d0fc30e00: e2e 11-root-relative — root 相対 symlink の相対形・移動耐性・stale 除去を実 nix で通す

## 対象

`tests/e2e/scenarios/11-root-relative.sh`（ハーネスは `tests/e2e/run.sh` / `tests/e2e/lib.sh`）

## 検証内容

一時的な git リポジトリに `mkRootRelativeSymlink` の entry を持つ fixture flake を作り、
project mode で実 nix から一気通貫に駆動する。

- **相対形で張られる** — subpath を持たない entry と持つ entry の双方で、readlink が `target` の
  親から `<src>/<subpath>` への相対文字列に一致し、リンク越しに内容へ到達できること
- **再 apply の冪等性** — 同じ設定の再 apply が layat の warning を出さず、readlink を変えないこと
- **移動に耐える** — リポジトリのディレクトリごと移動した後も readlink が変わらず、内容へ到達
  できること
- **移動先での再 apply** — 移動先は別の root として初回 apply になり、既存リンクの last-wins
  置換と前回記録が無い旨の warning だけを出して成功し、readlink を変えないこと
- **stale 除去** — entry を外した apply で外した entry のリンクだけが消え、残る entry と src の
  実体が保たれること

隔離した一時 HOME の下で動き、fixture flake は layat を局所パスの入力として参照し、依存を
lock の pin へ追従させてオフラインで評価する。
