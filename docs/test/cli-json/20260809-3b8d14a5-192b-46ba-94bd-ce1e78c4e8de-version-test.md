# CASE-3b8d14a5-192b-46ba-94bd-ce1e78c4e8de: version_test.go — バージョンの供給元一致・--version の出力書式・旧状態ディレクトリ検出ヒント

## 対象

`cmd/layat/version_test.go`

## 検証内容

- **埋め込み前の既定値** — リンク時の埋め込みが無いビルドで既定の値になること（テスト実行時は
  埋め込みを行わない前提を明示している）
- **供給元の一致** — CLI フレームワーク側のバージョンと内部のバージョン変数が同一であること。
  機械可読出力のツールバージョンがここから供給されるため、ドリフトすると文書の中身がずれる
- **出力書式** — `--version` の実出力が既定のテンプレートどおりの 1 行であること（独自
  テンプレートの混入を検出する）
- **提供しないものの固定** — 同名のサブコマンドが存在せず、フラグとしてのみ提供されること
- **検出ヒントの出力先** — 改名前の状態ディレクトリが残っているとき、サブコマンド実行で
  警告ストリームへ 1 度だけ出ること。残っていなければ何も出ないこと
- **検出ヒントと機械可読出力の分離** — 機械可読出力を選んだ実行で実際に文書を生成させ、
  その文書がヒントを含まないこと（標準出力は文書が専有し、ヒントは警告ストリーム側に出る）
- **検出の対象** — 同名のパスがディレクトリでない（通常ファイルである）ときは出ないこと。
  ヒントは世代を持つディレクトリとして案内するため、種別が違うものに出すと案内が事実と食い違う
- **状態ベースを解決できないとき** — 状態ベースの解決に失敗する環境では何も出ないこと。
  解決結果を確かめずに組み立てると相対パスの探索になり、作業ディレクトリ次第で誤検出する
- **検出ヒントの文面** — 旧ディレクトリの所在・世代を引き継がないこと・移行手引きの所在・
  放置すると旧世代が回収されないことの 4 点を含むこと（文言そのものではなく事実の網羅を見る）
- **検出ヒントを出さない経路** — バージョン表示・ヘルプ表示では出ないこと（それ自体が出力を
  目的とするフラグの書式の断言を壊さないため）
