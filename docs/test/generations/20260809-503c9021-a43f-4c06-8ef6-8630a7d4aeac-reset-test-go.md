# CASE-503c9021-a43f-4c06-8ef6-8630a7d4aeac: reset_test.go — FS-only teardown の除去範囲・フィルタ・dryrun・同意

## 対象

`internal/engine/reset_test.go`

共通ヘルパー `applyForReset` が事前条件として 1 世代を commit（profile が link farm を
指す状態）し、そこから `Reset` を駆動する tmpdir 統合テスト。`--root` 上書きで root を
固定し、git に依存しない。

## 検証内容

- 配置済みの symlink と copy target が除去される
- 別物を指すよう張り替えられた foreign symlink は保守的不変条件を満たさないため残し、
  `KeptForeign` へ載せて報告する
- target 引数で対象 entry を絞り込める
- 存在しない target 名はエラーで停止する
- `--dryrun` は除去予定を列挙するだけで FS を変更しない
- profile が無い（未 apply）状態の `reset` は no-op でエラーにしない
- 確認関数が false を返したら中断し、FS を変更しない
- 世代バックエンドを渡さない（`Backend` が nil の）`reset` はエラーで停止する
  （`TestResetRequiresBackend`）
- euid 0 以外を注入した system mode の `reset` は `fs.ErrPermission` を wrap したエラーで止まり、
  root・profile 基底・記録基底に何も作らない。同じ注入の `--dryrun` は通る
  （TC-be3d3dc9-1ead-4e2e-8eea-46e1c8884562）
