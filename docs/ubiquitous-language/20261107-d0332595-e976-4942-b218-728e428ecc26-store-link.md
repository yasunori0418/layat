# UBQ-d0332595-e976-4942-b218-728e428ecc26: store link

## Definition

The core, default placement: a symlink whose destination is a Nix store path. The default path that guarantees reproducibility. "Unification" means making the store the default/core and demoting out-of-store to an explicit exception.

## Avoid

Confusing it with out-of-store symlink; calling it a "copy".

"symlink" alone is ambiguous. Always disambiguate to either **store link** or **out-of-store symlink**. Out-of-store is expressed by `method = "symlink"` in `entries` (formerly `mode`) together with an out-of-store marker in `src`, but the default store link is itself realized as a symlink, so the bare word does not identify the kind.

"Unification" is not "removal". Store-link unification does not delete out-of-store; it demotes it from the default and isolates it behind an explicit function.

## 定義

コア・デフォルトの配置。配置先が Nix store パスである symlink。再現性を担保するデフォルトの使い方。「unification（統一）」とは、ストアをデフォルト / コアにし、out-of-store を明示的な例外へ降格することを意味する。

## 避ける表現

out-of-store symlink と混同すること、「コピー」と呼ぶこと。

「symlink」単独では曖昧。必ず **store link** か **out-of-store symlink** のどちらかに寄せる。`entries` の `method = "symlink"`（旧名 `mode`）+ out-of-store marker の `src` で out-of-store を指すが、デフォルトの store link も symlink で実現される。

「統一」は「廃止」ではない。store link の統一は out-of-store を消すことではなく、デフォルトから降格して明示関数に隔離すること。
