# ADR-6d7e2201-3101-4d67-9112-a7e85d8c2ea0: copy 内の symlink は symlink のまま複製する

- ステータス: 採用
- 日付: 2026-11-01
- 関連: `docs/spec.md`
- 起点: ADR-0016 §3 を書き直した

## 背景

store のディレクトリには symlink がよく含まれる。copy でディレクトリを再帰的に複製するとき、
src のツリーにある symlink を symlink として写すのか、指す先の実体を写すのかを決める必要があった。

## 決定

copy は src のツリーにある symlink をたどらず、symlink のまま複製する。相対 symlink はそのまま
保つ。store の中を指す絶対 symlink を複製すると、複製先が store に依存したまま残る。この性質は
docs に明記し、store から完全に切り離したい場合の対処は利用者に任せる。規範の細目は
REQ-0bd55dfc-b28c-4ad2-ad50-bb1f76b2246c に置く。

## 根拠

symlink のまま写せば、src のツリー構造をそのまま再現できる。たどって実体を写すと、循環する
symlink で止まらなくなったり、同じ実体を何度も複製してサイズが膨らんだりする。

## 棄却した代替案

### symlink をたどって実体をコピーする

store から完全に切り離せるが、循環する symlink とサイズの膨張を抱える。
