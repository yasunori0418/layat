# CASE-79561175-24f5-40a5-a031-509d7f90614b: e2e 09-apply-all — apply --all の辞書順集約・並列度非依存・前段衝突 error・--no-wait 併用

## 対象

`tests/e2e/scenarios/09-apply-all.sh`

## 検証内容

実 nix で `apply --all` を駆動し、並列化（→ ADR-0038 / ADR-0039）が利用者から見える形を
確かめる。fixture ごとに別 git repo（= 別 project root）を切り、lock・配置先を混ぜない。

- **辞書順集約** — 宣言順と辞書順をずらした 4 つの projectRoot config で、`--json` の
  `results[].subject.name` と `-v` の `layat: apply <name> done` 行が辞書順に並ぶこと
- **並列度非依存** — 定常状態で既定並列度と `--jobs 1` を続けて実行し、`results[]` が実行
  時刻（`startedAt` / `finishedAt`）を除いて同一であること
- **前段衝突 error** — 2 つの config が同じ target を持つ fixture で、`apply --all` と
  `--dryrun` が exit 1 で止まり、stderr に両 config 名と衝突 target を含み、衝突しない
  config も含めて何も置かれないこと。`--json` ではトップレベル `errors[]` に
  `E_LAYAT_FAILED` が 1 件載り `results[]` が空であること
- **`--no-wait` 併用** — 初回 apply（同じ root への並行配置を実際に通す）で進行中の apply が
  無ければ、集約行が applied 3 / skipped 0 / failed 0 で全 config が配置され、`--json` の
  全 subject が success であること
