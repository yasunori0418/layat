# TC-ddee6cc4-bc10-4107-bc7e-288a5fb62f1f: 終了コードの集約が優先順位に従い skip を失敗として数えない

## 条件

複数の対象を適用したときの終了コードが、個々の結果からの決めごとに従って決まることを確かめる。

- **優先順位が数値の大小ではない** — 一般エラーと dryrun の conflict が同時に起きたときは
  一般エラーが優先される。素朴に最大値を取ると conflict がエラーを覆い隠すため、両者が同時に
  現れる入力で明示的に確かめる
- **skip は失敗ではない** — 排他制御で着手を見送った対象は成功として数え、集約結果も成功に
  留まる。skip を失敗として数えると、何も破損していない実行が失敗として報告される
- **適用・skip・失敗の 3 値が別々に数えられる** — 部分失敗でも後続の対象を止めず、最後に
  集約する

終了コードとエンベロープの整合も条件に含む。dryrun の conflict では終了コードが conflict を
示しつつ、エンベロープ自体は正常に出力される（終了コードが 0 でないことと文書が欠けることは
別である）。
