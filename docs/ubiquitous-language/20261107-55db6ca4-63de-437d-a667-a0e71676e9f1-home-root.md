# UBQ-55db6ca4-63de-437d-a667-a0e71676e9f1: homeRoot

## Definition

The root marker selecting **home mode**. At runtime it resolves `$HOME` as **root**. It promotes the previously implicit `$HOME` default into an explicit marker. The applied form `homeRoot { subdir = ".config"; }` keeps root at `$HOME` and places every target under `.config/`.

## Avoid

Saying that the applied form resolves root to `$HOME/.config`.

## 定義

**home mode** を選ぶ root マーカー。実行時に `$HOME` を **root** に解決する。従来は暗黙だった `$HOME` の既定を明示マーカーへ昇格したもの。適用形 `homeRoot { subdir = ".config"; }` は root を `$HOME` のまま、全 target を `.config/` 配下へ置く。

## 避ける表現

適用形の root が `$HOME/.config` へ解決されると説明すること。
