# RISK-c3e92bb8-5806-48b0-8910-ee4fe236a325: starter テンプレが展開直後に評価を通らず最初の体験で行き止まる

## リスク

テンプレートは layat をはじめて使う人が最初に触れる成果物であり、展開した直後に評価が通らな
ければ、利用者は自分の書き方が悪いのか雛形が壊れているのか判断できないまま行き止まる。
テンプレートはプロダクト本体のコードから独立して壊れうる（本体の API を変えたときに追従を
忘れる）ため、本体のテストでは守れない。

固有の難しさは参照の循環にある。テンプレートは公開された layat を参照するので、リポジトリ内で
検証しようとすると「まだ公開されていない変更を含む手元の layat」ではなく公開版を見に行く。
これを局所の参照先へ差し替えられなければ、検証は手元の変更を反映しない。

加えて、layat が独自の flake 出力を持つことに由来する警告を、失敗と取り違える余地がある。
警告は許容する方針を採っているため、警告の有無ではなく評価が成功することで判定しなければ
ならない。

## 影響

新規利用者が最初の段階で離脱する。impact を medium とするのは、テンプレート自体は
`templates.standalone` / `templates.project` として公開される出荷物であり利用者の手元へ直接
届く一方、破れが評価の失敗として可視の形で現れ、テンプレートを直したうえでの再展開で
回復できるため。likelihood を medium とするのは、テンプレートが本体の API 変更に追従を
忘れる形で本体のコードから独立して壊れるため。e2e `06-init-templates`（展開元と評価時の
参照先の双方を局所リポジトリへ差し替えて `nix flake check` を通す）がこの退行を CI で
捕まえるので low 方向へ引かれるが、テンプレート固有の壊れ方は本体のテストが一切見ない。
