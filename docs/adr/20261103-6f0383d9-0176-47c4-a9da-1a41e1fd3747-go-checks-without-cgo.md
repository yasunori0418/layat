# ADR-6f0383d9-0176-47c4-a9da-1a41e1fd3747: Go の検査を CGO_ENABLED=0 で行う

- ステータス: 採用
- 日付: 2026-11-03
- 起点: 参照: PR #40、https://github.com/yasunori0418/cryoflow の CI 構成。ADR-0027 §3 を書き直した

## 背景

engine の Go の検査（go-vet と golangci-lint）は、flake check の check derivation として nix の
サンドボックスの中で実行する。サンドボックスに何を持ち込んで検査するかを決める必要がある。

## 決定

go-vet と golangci-lint の check derivation は、`CGO_ENABLED=0` のピュア Go で実行する。

check の構成は INF-d1230e1f-8ba8-49d8-8386-409bfbb7dd27 に置く。

## 根拠

layat の Go コードは cgo を使っていない。`CGO_ENABLED=0` にすれば、サンドボックスに C コンパイラを
持ち込まずに検査できる。C ツールチェインに依存しないので、検査の結果が決定論的になり、
サンドボックスの条件とも食い違わない。

## 棄却した代替案

### cgo を有効にしたまま検査する

使っていない cgo のために、サンドボックスへ C ツールチェインを持ち込むことになる。検査の入力が
増えるだけで、得るものが無い。
